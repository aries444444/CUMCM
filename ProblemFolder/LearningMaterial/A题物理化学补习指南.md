## 0. 题目识别（30 秒看懂这道题在考什么）

**本质**：一根长圆柱药材（长 25 cm、半径 2 cm）放在烘房里用热风吹干。烘房温度、湿度随时间变化。要预测药材**内部每一点的温度 T(r,t) 和水分浓度 C(r,t)**（干基含水率，kg 水/kg 干料）。

**物理过程**：
- 热量：烘房热空气 → 对流 → 药材表面 → **热传导** → 药材内部（温度由外向内渗透）。

- 两者通过"物性随水分/温度变化"耦合（附录 3/4 的经验公式）。

## 2. 模块 A：传热学（Heat Transfer）

### A1. 傅里叶导热定律（Fourier's Law）
热量沿温度梯度从高温流向低温：

**q = −k·∇T**　（q 为热流密度，W/m²；k 为热传导系数，W/(m·K)）

- k 表征材料导热能力。本题 k=0.36 W/(m·K)——比金属（铜 400）小 3 个量级，接近木材/植物组织，导热慢。

### A2. 热传导方程（Heat Equation）
取一个微元体做能量守恒：净流入的热 = 储存的热：

**ρ·c_p · ∂T/∂t = ∇·(k∇T)**

- ρ 密度（kg/m³）、c_p 比热容（J/(kg·K)）：升温 1 K 单位质量需要的热量。
- 物性为常数时：**∂T/∂t = α·∇²T**，α = k/(ρc_p) 称**热扩散率**（m²/s），是"温度传播速度"的唯一指标。
- 本题圆柱轴对称（只沿半径 r 变）：∇²T = (1/r)·∂/∂r(r·∂T/∂r)，即

**ρc_p ∂T/∂t = (1/r)·∂/∂r(r·k·∂T/∂r)**

### A3. 牛顿冷却定律（对流换热，Convection）
固体表面与流体的换热速率 ∝ 温差：

**q_conv = h·(T_air − T_surface)**　（h 为对流换热系数，W/(m²·K)）

- h=25 W/(m²·K) 对应低速热风/自然对流量级（典型 5~100）。
- 作为**第三类（Robin）边界条件**：表面导出的热 = 对流带走的热：

**−k·∂T/∂r |_{r=R} = h·(T(R,t) − T_air(t))**

### A4. 毕渥数 Bi（Biot Number）—— 本题第一个关键判断
Bi = 内部导热阻力 / 表面对流阻力 = **h·Lc / k**（Lc = V/A 特征长度，长圆柱 Lc = R/2）。

- Bi ≪ 0.1：内部温度基本均匀，可用**集总参数法**（一个 ODE 就完事）。
- Bi ≥ 0.1：内部有显著温度梯度，必须解 PDE。
- **本题**：Bi = 25 × 0.01 / 0.36 ≈ **0.7**（或按 hR/k = 1.39 算）≫ 0.1 → **必须用分布参数 PDE 模型**，中心与表面温度差异显著。论文里先算 Bi 是标准起手式。

### A5. 时间尺度：傅里叶数 Fo = αt/R²
- 本题 α = 0.36/(820×2600) ≈ 1.7×10⁻⁷ m²/s，R=0.02 m → 热渗透时间 R²/α ≈ **2400 s ≈ 40 min**。
- 即：预热 30 min 结束时，中心温度**还没**跟上烘房温度——这正好解释问题 1 为什么要算 1800 s。

## 3. 模块 B：传质学（Mass Transfer / Diffusion）

### B1. 菲克定律（Fick's Laws）—— 与傅里叶定律完全同构
- 第一定律（通量）：**J = −D·∇C**　（J 为水分通量，D 为扩散系数 m²/s）
- 第二定律（守恒）：**∂C/∂t = ∇·(D∇C)**；D 为常数时 ∂C/∂t = D∇²C。
- 圆柱轴对称：**∂C/∂t = (1/r)·∂/∂r(r·D·∂C/∂r)**

> **类比记忆**：T ↔ C，α ↔ D，k ↔ ρ·D，h ↔ h_m。传热学的所有解法、边界条件套路原样搬到传质。一个求解器通吃两个方程。

### B2. 对流传质（Convective Mass Transfer）
表面水分蒸发通量 ∝ 表面与烘房空气的浓度差：

**−D·∂C/∂r |_{r=R} = h_m·(C(R,t) − C_air(t))**　（h_m 为对流传质系数，题给 8×10⁻⁷ m/s）

- 注意量纲：C 是 kg/kg（无量纲浓度），h_m 是 m/s，方程两侧都是 (kg/kg)·m/s，自洽——**不需要**再乘密度。这正是题面用"干基含水率"当浓度变量的原因。

### B3. 非线性扩散 —— 本题核心难点之一
题给 D = 7×10⁻⁹ e^(−0.89/C)（问题 1）或 D = 2.4×10⁻³ e^(−0.45/C) e^(−3850/T)（问题 2~4）：D 是 C（和 T）的函数 → 方程是**拟线性抛物方程**，必须数值求解；解析解只对"冻结 D"成立（可作验证）。注意 C 在指数**分母**上：D 随 C 下降而减小，越干扩散越慢。

### B4. 对流传质毕渥数 Bi_m = h_m·R / D
问题 1：Bi_m = 8×10⁻⁷ × 0.02 / 4.9×10⁻⁹ ≈ **3.2** > 1 → 内部扩散阻力主导，表面 C 较快趋近 C_air，干燥由内部扩散控制。这是很好的论文分析点。

### B5. 水分浓度 C 的定义（干燥工程专用变量）
- **干基含水率 C = m_水 / m_绝干料**（kg/kg，本题用这个）。
- 湿基含水率 w = m_水 / (m_水 + m_干料)。
- 换算：**w = C/(1+C)**，**C = w/(1−w)**。
- 用干基的原因：干燥中绝干料质量不变，方程最简单。
- 初始 C=2.55 kg/kg 意味着：每 1 kg 干药材里含 2.55 kg 水（≈72% 湿基含水率）——这是**鲜药材**，水很多。

## 4. 模块 C：干燥原理（化工原理"干燥"一章）

### C1. 干燥三阶段（理解结果形态的钥匙）
1. **预热阶段**：药材升温快、失水少。表面蒸发量小，热主要用于升温。（= 问题 1）
2. **恒速干燥阶段**：表面充分湿润，蒸发速率恒定，由**外部条件**（烘房温度、湿度、风速）控制；表面温度≈湿球温度。
3. **降速干燥阶段**：表面水分不足，干燥速率由**内部扩散**控制，随 C 下降而持续下降；温度继续升高趋近烘房温度。干燥主体时间耗在这里。

### C2. 几个概念
- **临界含水率 C_c**：恒速段与降速段的分界。
- **平衡含水率 C_eq**：与烘房空气达到平衡、永远烘不掉的水分。干燥极限是 C_eq，不是 0。问题 3 的 0.15 是**工艺要求**，高于平衡值。
- **自由水/结合水**：自由水（孔隙中，易烘）vs 结合水（吸附/化学结合，难烘）。降速段后期烘的主要是结合水，所以慢。
- **水分比 MR = (C − C_eq)/(C₀ − C_eq)**：文献常用无量纲量，画干燥曲线、验证模型时用。

### C3. 本题的模型如何自动体现三阶段
扩散+对流传质模型本身就会给出"表面先干、中心滞后"的行为。论文中结合模拟曲线讨论"预热段失水仅限表面 ~3 mm 薄层（√(Dt) 估算）、恒温段速率趋稳、降速段指数衰减"会非常加分。

## 5. 模块 D：物理化学基础

### D1. 阿伦尼乌斯公式（Arrhenius Equation）
温度对过程速率的指数放大：**k_rate = A·e^(−Ea/(R_g·T))**

- Ea 活化能（J/mol），R_g = 8.314 J/(mol·K)，**T 必须用开尔文**。
- 本题 D 里的 e^(−3850/T)：对比知 **Ea/R_g = 3850 → Ea ≈ 32.0 kJ/mol**。食品/药材干燥实测活化能典型 12~45 kJ/mol，题给公式在合理区间内。
- 应用：D(60°C)/D(30°C) = e^(3850/303 − 3850/333) = e^1.145 ≈ 3.1 倍。温度对烘干速度影响很大。

### D2. 汽化潜热（Latent Heat of Vaporization）
- 水汽化潜热 L_v ≈ 2.26×10⁶ J/kg（100°C），2.45×10⁶ J/kg（20°C）。
- 表面蒸发会**带走热量**（蒸发冷却）：q_evap = L_v·J_evap。
- **本题注意**：题给参数表里**没有** L_v，说明标准模型的热边界就是纯对流（第 A3 条），不做蒸发冷却项。可在论文"模型扩展/讨论"里加这项并给出对比（会更有深度，但别把主结果押在上面）。

### D3. 经验式怎么读（附录 3/4）
ρ=650+128C、c_p=1450+2736·C/(C+1)、k=0.21+0.38·C/(C+1) 之类是**拟合式**：含水越多，密度、比热、导热系数都变大（水比空气导热好、比热大），物理上合理。建模时直接套用即可，不必推导。

## 6. 模块 E：数值方法要点（这是你的主场，只说易错点）

### E1. 圆柱坐标守恒型离散（千万别直接中心差分 ∇² 的 1/r 项）
用守恒形式（通量在控制体积上积分）：
(1/r)∂/∂r(r·k·∂T/∂r)|_i ≈ [ r_{i+1/2}·k_{i+1/2}·(T_{i+1}−T_i) − r_{i−1/2}·k_{i−1/2}·(T_i−T_{i−1}) ] / (r_i·Δr²)

- **r=0 奇性**：由对称性 ∂T/∂r=0，中心点直接用 (1/r)∂(r∂T/∂r) → 2·∂²T/∂r²（洛必达）或 ghost cell。

### E2. 时间推进与稳定性
- 显式 Euler：Δt ≤ Δr²/(2α_max)（圆柱中心更严）。本题 α≈1.7×10⁻⁷，Δr=1 mm 时 Δt ≤ 3 s；Δt=1 s 勉强可行但太贴边。
- **推荐 Crank–Nicolson**（无条件稳定、二阶）：每步解三对角方程组（Thomas 算法，21 格点瞬解）。
- 问题 2~4 需模拟 2~3 天（~2×10⁵ s）：Δt 取 1~10 s，隐式完全无压力。

### E3. 非线性与耦合的处理（本题最关键的程序设计决策）
物性 ρ(C)、c_p(C)、k(C)、D(C,T) 随解变化 → 每步**系数滞后迭代**：用上一时刻（或上次迭代）的 C、T 算系数 → 解隐式线性方程组 → 更新 → 迭代 1~3 次收敛。热、质两个方程交错求解（先 T 后 C 再 T…）。

### E4. 时变边界条件
附件 1 的 T_air(t)、C_air(t) 是离散数据：线性插值（或样条）后代入边界条件，切忌阶跃。

### E5. 移动边界（问题 4）：Landau 变换
令 ζ = r/R(t) ∈ [0,1]，把时变域 [0,R(t)] 变成固定域 [0,1]：

- 水分：**∂C/∂t − (ζR′/R)·∂C/∂ζ = (1/(R²ζ))·∂/∂ζ(ζ·D·∂C/∂ζ)**
- 温度：**ρc_p·(∂T/∂t − (ζR′/R)·∂T/∂ζ) = (1/(R²ζ))·∂/∂ζ(ζ·k·∂T/∂ζ)**
- 表面 ζ=1 边界：−(k/R)∂T/∂ζ = h(T−T_air)；−(D/R)∂C/∂ζ = h_m(C−C_air)。
- **变换后多出一阶对流项 −(ζR′/R)∂/∂ζ**（因为网格随表面移动）——忘掉它会得到系统性错误。
- R(t) 直接由附件 2 数据插值给出（数据已隐含收缩规律，不需要从失水量推导收缩；可在论文里讨论"体积收缩≈失水体积"的自洽性）。
- 简化替代方案：不变换坐标，直接在离散网格上让 R(t) 落在最靠近的格点上（网格随表面增减）——一阶精度但省事，可作为交叉验证。

### E6. 结果文件（已核对附件 3 模板）
- result1/2.xlsx：**两个 sheet**（「温度」「水分浓度」），A 列时间、第 1 行距离 0:0.1:2 cm（21 列），保留 4 位小数。模板首行时间从 1 s 起（与 result3 从 60 s 起一致）→ **行从 t=1 s（result1）或 t=0 起均可，建议以模板为准：不含 t=0 行**（result2 同理 1~10800 s）。

## 8. 本题模型组装（每问的方程清单）

### 问题 1：预热平衡阶段（附录 2 参数，t ∈ [0, 1800 s]）
```
热：  820×2600·∂T/∂t = (1/r)∂/∂r(r·0.36·∂T/∂r)
质：  ∂C/∂t = (1/r)∂/∂r(r·D(C)·∂C/∂r)，  D = 7×10⁻⁹·e^(−0.89/C)
初值：T(r,0)=28，C(r,0)=2.55
边界：r=0：∂T/∂r=∂C/∂r=0（对称）
      r=0.02：−k∂T/∂r = 25·(T−T_air(t))；−D∂C/∂r = 8×10⁻⁷·(C−C_air(t))
      T_air(t)、C_air(t) 来自附件 1（离散数据插值）
```
- **关键洞察**：D 只含 C、物性全是常数 → 热方程与质方程**解耦**，两个独立抛物线问题，都可独立求解。
- 预期形态：1800 s 内温度从外向内渗透（√(αt)≈1.7 cm），水分只在表面 ~3 mm 薄层变化（√(Dt)≈3 mm），中心 C 几乎不动。
- **附件 1 实际数据**：前 1800 s 烘房仅升至 ≈29.7 °C、C_air≈0.021 —— 预热初期驱动很弱，药材温度、水分变化都很小（可作为论文 sanity check：表 1 数值应非常接近初值）。
- 数学加分项（你的优势）：线性问题可用 Duhamel 原理 + 卷积处理时变烘房温度；常数边界下 T 有 J₀ Bessel 级数解析解，β_n 由 βJ₁(β)=Bi·J₀(β) 给出——用来验证数值解。

### 问题 2：全过程（附录 3 经验式）
```
物性：ρ=650+128C，c_p=1450+2736·C/(C+1)，k=0.21+0.38·C/(C+1)
      D = 2.4×10⁻³·e^(−0.45/C)·e^(−3850/T)   ← T 用开尔文！
方程与边界同上（h=25、h_m=8×10⁻⁷ 沿用附录 2）

```
- **双向耦合**：D 依赖 T 和 C；ρ、c_p、k 依赖 C → 必须交错迭代求解。
- 烘房条件（已核对附件 1）：0~4 h 用附件 1 数据（28→50 °C，0.0196→0.05）；4 h 之后进入恒温干燥段，取附件 1 末值恒定（**T_air≈50 °C、C_air≈0.05 kg/kg**，论文中写明此假设）。

### 问题 3：烘干时长（附录 3 公式，同问题 2 模型）

## 9. 数值解验证清单（写论文的硬通货）

1. **网格收敛**：Δr = 1、0.5、0.25 mm，Δ t 同步减半，解变化 < 1% → 报告。
2. **守恒检验**：总水量 ∫ρ_d·C·dV 的减少量 = 表面累计通量 ∫h_m(C_s−C_air)dA dt（数值算两边对比）。
3. **解析锚点**：常数烘房条件下，T(r,t) 与 J₀-Bessel 级数解对比（问题 1 冻结 D 同理对比 C）。
4. **渐近行为**：t→∞ 时 T→T_air、C→C_air（边界为常数时）。
5. **量级直觉**：√(αt)、√(Dt) 渗透深度与曲线形态对照（30 min 内水分只动表面薄层）。
6. **Bi 数分析**：Bi≈0.7 → 内部温度梯度不可忽略（呼应用 PDE 的必要性）；Bi_m≈3.2 → 内部扩散主导，表面水分较快跟随烘房。

## 11. 十大易错点（打印贴墙上）

1. **e^(−3850/T) 里的 T 是开尔文**，忘了 +273.15 直接错 3 个量级。
2. 半径要用米：R = 0.02 m，不是 2。
3. 圆柱离散要用守恒型 (1/r)∂(r∂/∂r)，直接差分 1/r 项在 r=0 爆炸。
4. D、k、ρ、c_p 随 C/T 变 → 系数必须滞后迭代，显式一步到位会发散。
5. 问题 1 中热、质方程解耦（D 不含 T）——别把问题做复杂。
6. 问题 2~4 中两方程强耦合（D 含 T）——别忘了交错求解。
7. Landau 变换后多一个对流项 −(ζR′/R)∂/∂ζ。
8. 附件 1 数据要插值后进边界条件（0~4 h 爬坡）；4 h 后恒温段取末值 T_air≈50 °C、C_air≈0.05 恒定并**在论文里写明假设**。
9. 输出保留 4 位小数；result 文件的列 = 距离（0:0.1:2）、行 = 时间，别转置错。
10. 答案量级自检：t* 小时~天量级；若模拟 1 分钟烘干或 1 年烘不干，先查单位，再看 e 指数符号。
