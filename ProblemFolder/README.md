# Visualization —— 数据可视化

2026 CUMCM A 题 · 药材的烘干问题 · 结果图表

## 目录内容

| 文件 | 说明 |
|---|---|
| `visualize.py` | 绘图脚本（一键生成全部 3 张图） |
| `fig1_overview.png` | 总览四联图：中心对比 / 收缩 / 位置演化 / 径向剖面 |
| `fig2_heatmap.png` | 含水率时空热力图（问题3 vs 问题4，含动边界） |
| `fig3_validation.png` | 模型检验汇总（误差量级 + 烘干时长对比） |

## 运行

```powershell
cd CUMCM\Visualization
python visualize.py
```

**依赖**：`numpy`、`openpyxl`、`matplotlib`（需中文字体 SimHei / Microsoft YaHei）。
数据自动从 `../ProblemFolder/` 读取，无需手工准备。

## 数据源

| 文件 | 用途 |
|---|---|
| `ProblemFolder/result3.xlsx` | 问题3 水分浓度（每 60 s，0~2 cm，3419 行） |
| `ProblemFolder/result4.xlsx` | 问题4 水分浓度（每 60 s，0~2 cm + 药材表面，3042 行） |
| `ProblemFolder/OriginalMaterial/A题/附件/附件2.xlsx` | 收缩半径 $R(t)$（145 点，2.000 → 1.198 cm） |

## 各图说明

### 图 1 · 总览四联图（`fig1_overview.png`）

- **(a) 中心含水率随时间演化**：问题3（蓝，无收缩）vs 问题4（红，含收缩）对比，
  标出判据线 $C=0.15$ 与两个烘干结束时刻。两条曲线在 **约 41 h 交叉**——
  前期问题4更慢（附录4的 $D$ 小），后期反超（收缩累积效应）。
- **(b) 尺寸收缩与表面失水**：双轴图，$R(t)$ 收缩 40.1%，67 h 后稳定于 1.198 cm；
  表面含水率在 12 h 内即降至 ~0.17 kg/kg。
- **(c) 问题4 各位置含水率演化**：$d=0/0.5/1.0$ cm 及表面；
  $d=1.5$ cm 处约 3.5 h 后移出药材（$d=2.0$ cm 自初始即为表面）。
- **(d) 径向剖面随时间的收缩**：5 个时刻的 $C(d)$ 剖面，虚线标出该时刻实际表面 $R(t)$，
  直观显示有效扩散域不断缩小。

### 图 2 · 时空热力图（`fig2_heatmap.png`）

并排对比问题3（固定域，$R\equiv2$ cm）与问题4（动边界）的 $C(d,t)$ 分布，
两图横轴统一为 0~60 h，蓝/红竖虚线分别为各自的 $t^*$。
**色标方向：含水率越高颜色越深**（2.55 kg/kg → 深蓝，0 → 淡黄）。
右图以红色曲线叠加实际表面 $R(t)$，热力数据在该曲线外被裁掉，直观体现"收缩"。

### 图 3 · 模型检验汇总（`fig3_validation.png`）

- **(a) 误差量级（对数轴）**：V1 守恒闭合差、V2 时间收敛、V3 网格收敛，
  橙色虚线为"四位小数"目标 $10^{-4}$。可见 **V3 网格收敛误差 ≈5.3×10⁻⁴ 已越过目标线**
  （对应 `问题四分析_发现的问题.md` 中的第 2 条问题）。
- **(b) 收缩对烘干时长的影响**：$t^*$ 由 56.97 h 缩短至 50.69 h，减少 6.27 h（约 11%）。

## 已知注意事项

1. `fig3(a)` 中对数轴刻度使用**纯文本格式**（如 `1e-4`）而非默认的数学排版，
   以规避 SimHei 缺少 U+2212（减号）字形导致的告警。
2. 图2 右图在 $d>R(t)$ 处为空白（无药材），与题面表 6 的 `---` 规则一致。
3. `fig3(a)` 的误差数值来源为 `ProblemFolder/q1~q4_out.txt`，属硬编码；
   若重跑求解器导致数值变化，需同步更新脚本中的 `vals` 列表。
