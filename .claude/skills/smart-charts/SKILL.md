# smart-charts —— A 题论文交互图表

## 打开方式

- Windows 资源管理器双击;或命令行 `start "<文件名>"`。

## 修改与数据同步(硬约束)

1. 图内数据以 **result1–4.xlsx(四位小数)与附件 1/2 为准**。任何图上的关键数值(如 Q1 表面 1800 s 温度 36.79 °C、水分 1.5102 kg/kg)必须与论文表 1–6 及 xlsx 逐格一致;不一致时改图,不改表。
2. 数据内嵌于各 HTML 的 ECharts `option` 的 series/data 中,直接编辑即可;生成脚本如更新,重新输出后按清单核对。
3. 求解器重跑或论文数值更新后(如加密空间离散后的 `t*=57.0875 h`(问题 3)、`t*=50.7722 h`(问题 4)),必须同步更新图表并重命名文件标题。
